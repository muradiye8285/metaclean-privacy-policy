Support

Need help with MetaClean? Start with the common issues below.

Save does not work

MetaClean needs permission to add cleaned copies to your Photo Library.

  • Open iPhone Settings.
  • Go to Privacy & Security > Photos.
  • Find MetaClean.
  • Allow MetaClean to add photos, or choose Add Photos Only if that option is shown.

Share is disabled

The share button becomes active after MetaClean creates cleaned copies. Select photos first, then run the clean step.

My original photos changed

MetaClean is designed to create cleaned copies. It does not overwrite the original image files in your library.

What data does MetaClean remove?

MetaClean removes hidden metadata such as GPS location, device details, camera information, and similar technical photo metadata before sharing.

Does MetaClean upload my photos?

No. MetaClean is built to process photos on-device and does not upload them as part of the core cleaning workflow.
