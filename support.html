Support

Need help with MetaClean? Start with the common photo and video questions below.

Save does not work

MetaClean needs permission to add cleaned copies to your Photo Library.

  • Open iPhone Settings.
  • Go to Privacy & Security > Photos.
  • Find MetaClean.
  • Allow MetaClean to add photos and videos, or choose Add Photos Only if that option is shown.

Share is disabled

The share button becomes active after MetaClean creates cleaned copies. Select a photo or video first, then run the clean step.

Which formats are supported?

Photos: JPEG, HEIC, and PNG. Videos: MOV, MP4, and M4V. Some video files may not export if iOS does not support that file's encoding or container combination.

My original files changed

MetaClean is designed to create cleaned copies. It does not overwrite the original photos or videos in your library.

What data does MetaClean remove?

MetaClean removes supported hidden metadata such as GPS location, device details, camera information, creation data, and similar technical media metadata before sharing.

Does MetaClean upload my media?

No. MetaClean is built to process photos and videos on-device and does not upload them as part of the core cleaning workflow.

A video says export failed

MetaClean supports common iPhone video formats, including HEVC videos saved as MOV, MP4, or M4V. If export fails, try saving the video from the Photos app again or use a shorter copy; very large files or unusual file containers can fail when iOS cannot create a cleaned export for that specific file.
