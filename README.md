# Privacy Policy - MetaClean

MetaClean is a privacy-focused iOS and Android application designed to remove metadata from photos and videos before sharing.

## Media Processing
Photo and video processing happens locally on the user's device.
Selected media is never uploaded to any server.

## Platform Services
The iOS version does not include advertising or analytics. The free Android version uses Google Mobile Ads, Google User Messaging Platform, Google Play Billing, and Google Play's review service as described in the public privacy policy.
